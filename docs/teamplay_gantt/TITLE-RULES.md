# 𝗙𝗫팀 두레이 업무 제목 규칙

> 이 문서는 **지속 관리 대상**입니다. 새로운 케이스가 생기거나 규칙이 바뀌면 이 파일을 수정하고 맨 아래 **변경 이력**에 한 줄 남겨주세요.
> 앱에서 열기: `V` 키 → "제목 규칙" 탭

---

## 1. 기본 형식

```
𝗙𝗫 [플랫폼] 프로젝트 [상태태그] 업무명
```

| 세그먼트 | 의미 | 예 |
|---|---|---|
| `𝗙𝗫` | FX팀 업무 식별 접두사 (굵은 산세리프 특수문자, 고정) | `𝗙𝗫` |
| `[플랫폼]` | 대괄호 안 플랫폼 | `[PC포커]` `[서브앱]` `[공통]` |
| `프로젝트` | 플랫폼과 상태태그 **사이** 텍스트 = 프로젝트명 | `로우바둑이` `4월 업데이트` |
| `[상태태그]` | 업무 종류 라벨 (Task Status와 무관) | `[작업]` |
| `업무명` | 마지막 상태태그 **뒤** 전체 = 실제 업무명 | `WIN 연출 밝기 및 색상` |

시스템이 제목을 읽을 때 **첫 대괄호 = 플랫폼**, **마지막 대괄호 = 상태태그**, 그 사이 = 프로젝트, 뒤 = 업무명으로 분해합니다.
(파싱: `commentParser.js parseTaskTitle`, 업로드 비교: `syncManager.js pushTaskToDooray`)

---

## 2. 도구별 실제 생성 형식 (현재 반영되는 규칙)

| 생성 경로 | 실제 생성 제목 | 비고 |
|---|---|---|
| **두레이 새 업무** (사이드 패널) | `𝗙𝗫 [플랫폼] 프로젝트 [선택태그] 업무명` | `taskCreator.js _buildSubject` |
| **QA 업무 등록** (QA URL 변환) | `𝗙𝗫 [플랫폼] N월 업데이트 [작업] 내용` | `qaRegister.js _buildSubject` |
| **팀플레이 자동 생성** | `🔥𝗙𝗫 [팀플레이] YYYY.M월 N주차 (MM~MM)` | `automationPanel.js` |

- **두레이 새 업무**: 태그를 드롭다운에서 선택 가능 (기본: `[작업]`)

  | 선택 태그 | 용도 |
  |---|---|
  | `작업` (기본) | 일반 작업 업무 |
  | `일정` | 프로젝트 일정 계획 문서 |
  | `QA` | QA 대응 업무 |
  | `완료` | 완료 처리 업무 |
  | `기획` | 기획 관련 업무 |

- **QA 등록·팀플레이 생성**: 상태태그가 고정값으로 자동 생성됩니다.
- 플랫폼·프로젝트·업무명만 입력하면 `𝗙𝗫` 와 태그는 도구가 자동으로 넣습니다.

## 3. 예시

```
𝗙𝗫 [PC포커] 4월 업데이트 [작업] 바로입장 버튼 연출
𝗙𝗫 [서브앱] 로우바둑이 [작업] WIN 연출 밝기 및 색상
𝗙𝗫 [공통] 포커리그 개편 [작업] 리그 등급 아이콘 7종
```

## 4. 주의사항 (제목이 깨지는 경우)

1. **`𝗙𝗫` 는 일반 영문 "FX"가 아님** — 굵은 산세리프 특수문자(`𝗙𝗫`)입니다. 수기 작성 시 기존 제목에서 복사하세요. (도구로 만들면 자동 입력)
2. **대괄호 `[ ]` 는 플랫폼/상태태그 전용** — 프로젝트명·업무명에 `[ ]`를 쓰면 플랫폼/상태로 오인되어 파싱이 깨집니다. (부득이하면 본문 링크에서 `&#91;` `&#93;` 로 이스케이프)
3. **프로젝트명 띄어쓰기 = 그룹 키** — Gantt 그룹은 프로젝트명 문자열 그대로라, `로우바둑이QA`(붙임)와 `로우바둑이 QA`(띄움)는 서로 다른 그룹이 됩니다. 표기를 통일하세요.

## 5. 특수 케이스

### 5-1. 카테고리 / 조직(Organization)
- **카테고리**: 제목이 아니라 **본문 `* 카테고리:`** 에 기록됩니다. (제목에 `프로젝트 | 카테고리` 형식도 인식되지만, 새 업무 생성 시엔 본문에 넣습니다)
- **조직(담당팀)**: 제목에 없고 **본문 `* 조직:`** 에 기록 → 보고서 그룹핑 기준.

### 5-2. 공통 플랫폼 분리
`[공통]` 플랫폼 업무를 PC/클래식 등으로 나눌 때는 **업무명 앞에 소괄호 prefix**:
```
𝗙𝗫 [공통] 포커리그 개편 [작업] (PC) 브리핑/알리미
𝗙𝗫 [공통] 포커리그 개편 [작업] (클래식) 브리핑/알리미
```
대괄호는 플랫폼/상태 전용이므로 소괄호를 사용합니다.

### 5-3. QA 대응 건
정규 작업 리스트와 분리하기 위해 별도 컨벤션 적용:
```
𝗙𝗫 [플랫폼] {프로젝트} QA [작업] {QA 현상}     ← 프로젝트명 뒤 "공백 + QA"
본문 * 조직: QA
```
- 예: `𝗙𝗫 [서브앱] 로우바둑이 QA [작업] WIN 연출 밝기 및 색상`
- 효과: Gantt에서 `{프로젝트} QA` 별도 그룹, 보고서에서 QA 섹션으로 분리.
- 참고: 본문 `* 위키:` 바로 다음 줄 `* 기획: [원본링크]` 는 planningTitle로 파싱되어 **월 업데이트 Copy Table** 행 제목이 그 링크 텍스트로 표시됨 (의도면 OK).

    주간보고 자동화 규칙¶

    전체 흐름¶

    매주 목요일 주간보고를 자동으로 생성하는 프로세스입니다.

    팀플레이 생성 -> Sync -> 댓글 조회 -> 표 생성 -> 본문 업데이트

    1. 팀플레이 생성¶

    제목 규칙¶

    형식: FX [팀플레이] {년도}.{월}월 {주차}주차 ({월요일}~{금요일})

    항목 규칙 예시
    년도 4자리 2026
    월 금요일 기준 월 (보고서와 동일) 3월
    주차 해당 월의 주차 번호 4주차
    기간 월~금 날짜 03.24~03.28

    예시: FX [팀플레이] 2026.3월 4주차 (03.24~03.28)

    본문 구성¶

    1. 이전주 링크: dooray:// 프로토콜로 이전 팀플레이 업무 링크
    2. 12컬럼 빈 표: 주간보고 데이터가 채워질 빈 마크다운 표

    생성 조건¶

    • 이번 주 동일 패턴 팀플레이가 이미 있으면 생성 안 함 (중복 방지)
    • 이전 주 팀플레이를 검색하여 정재화 댓글을 새 업무에 복사

    예약 자동 생성¶

    • 설정 위치: Automation 패널 > 목요일 루틴 > 예약 자동 생성
    • 설정 항목: 요일, 시, 분 (기본: 금요일 09:00)
    • 하루 1회 제한: 같은 날 중복 생성 방지
    • 놓친 예약 보완: 앱 시작 시 오늘 예약이 지났으면 알림

    2. 댓글 형식 (팀원 작성)¶

    각 팀원이 팀플레이 업무에 댓글로 주간 진행사항을 작성합니다.

    댓글 구조¶

    [프로젝트코드/번호 업무제목](dooray://orgId/tasks/postId)

| No | 금주 진행내용 | 다음주 주요 액션 | 이슈 | 팀 공유사항 |
| --- | --- | --- | --- | --- |
| 1 | 03.19 작업내용 | 다음 계획 | 이슈 | 공유사항 |

    파싱 규칙¶

    규칙 설명
    링크+표 쌍 링크 바로 아래 표가 하나의 프로젝트 단위
    "금주 진행내용" 컬럼 필수 이 헤더가 없는 표는 무시
    MM.DD 패턴 날짜 자동 추출 (Work 마크 적용)
    "새 업무 등록" 팀 공유사항에 기재 시 Gantt Task 자동 생성
    HTML 표 호환 마크다운 \| col \|과 HTML <table> 모두 지원

    표 형식 주의사항¶

    • 김보람: 마크다운 표 사용
    • 정재화, 김지인: HTML <table> 태그 사용
    • 파싱 로직은 HTML 먼저 시도 후 마크다운 fallback

    3. 주간보고 표 생성¶

    표 컬럼 (Weekly 설정)¶

    컬럼 키 설명 기본
    No no 순번 O
    업무구분 category 카테고리 O
    업무명 task 프로젝트+Task명 O
    담당자 assignee 작성자 O
    일정 schedule 시작~종료일 O
    진척률 progress Gantt 진행률 O
    우선순 priority 우선순위 O
    금주 진행내용 thisWeek 이번 주 작업 O
    다음주 주요 액션 nextWeek 다음 주 계획 O
    이슈 issue 이슈 사항 O
    팀 공유사항 teamShare 공유 사항 O
    위키 wiki 위키 링크 X

    조직 순서 (Order)¶

    • Settings > 주간보고 그룹명에서 조직 그룹 매핑 설정
    • 표에 조직 구분 행이 삽입됨 (배경색 + 그룹명)
    • 드래그로 조직 순서 변경 가능

    조직 그룹 매핑¶

    그룹 매핑되는 조직
    기획팀 포커게임기획, 포커게임기획팀
    사업팀 사업, 포커서비스기획, 포커서비스기획팀
    운영 포커운영, 포커운영팀, 포커사업팀

    표 옵션¶

    옵션 설명
    날짜 접두사 제거 "03.19 작업내용" → "작업내용"
    URL 축약 긴 Dooray URL을 축약 형태로
    위키 포함 위키 컬럼 추가
    Task 정렬 원본순 / 프로젝트순

    4. 본문 업데이트¶

    팀플레이 (FX팀)¶

    • 기존 본문의 표를 새로 생성된 표로 교체
    • 표 외 본문(이전주 링크 등)은 보존
    • 표 초기화: 데이터 행을 빈 1행으로 교체하는 별도 기능

    아트실 주간보고¶

    새 Dooray 업무를 생성하여 아트실 주간보고를 작성합니다.

    생성 내용:

    항목 규칙
    제목 [N월 DD일] 보고자명 (다음 목요일 기준)
    팀명 설정된 팀명 (기본: 클래식FX팀)
    주간 요약 프로젝트별 Task 상태 요약
    표 FX팀 Weekly 표와 동일

    주간 요약 형식: 

    * **[프로젝트] :** Task1 완료, Task2 진행중 (진척률 N%)

    5. 아트실 주간보고 댓글¶

    아트실 주간보고 업무 생성 후, 개인 작업 내용 + 이미지를 댓글로 자동 작성합니다.

    대상 기간¶

    • 목~목: 지난주 목요일 ~ 이번주 목요일

    댓글 구조¶

    서비스 카테고리(포커/바둑/기타) → 프로젝트 → Task 순서로 그룹핑합니다.

    서비스 카테고리 매핑¶

    카테고리 포함 플랫폼
    PC포커 / 클래식 클래식, 서브앱, 공통, PC포커, PC, 홀덤, 포커클래식
    PC바둑 / 모바일 바둑 PC바둑, 모바일, PC바둑오목, M바둑오목, PC장기, PC신윷놀이, PC사천성

    이미지 규칙¶

    • 파일명 패턴: *_Final.(png|webp|jpg|jpeg) (대소문자 무시)
    • 소스: Dooray 업무 첨부파일 (post.files[])
    • 참조 방식: ![filename](/files/fileId) — cross-post 참조 (re-upload 불필요)

    세부 내용¶

    • AppState.dailyNotes에서 해당 기간 내 노트 수집
    • 줄바꿈으로 분리 → 중복 제거 → 콤마 구분

    상태 표시¶

    Task 상태 표시
    Done 또는 100% 완료
    그 외 진행 중 (빨간색)

    LLM 문장 다듬기 (선택)¶

    • 플래그: artCommentLlmRefine (Automation 패널에서 토글)
    • 모델: Groq API (llama-3.3-70b-versatile)
    • 동작: 댓글 마크다운 전체를 LLM으로 문장 다듬기 후 교체

    6. 원클릭 루틴 (주간보고 작성)¶

    Automation 패널에서 한 버튼으로 전체 프로세스를 순차 실행합니다.

    파이프라인 단계¶

    단계 이름 동작
    1 Sync 팀플레이 검색 → 댓글 Sync → 변경 적용
    2 댓글 조회 + 파싱 headless fetchComments → 파싱 → 병합
    3 표 생성 Weekly 마크다운 표 생성
    4a 본문 업데이트 [팀플레이] Dooray PUT
    4b 아트실 생성 [아트실] Dooray POST + 댓글 작성

    루틴 대상 선택¶

    대상 Step 4 동작
    팀플레이 (FX팀) 기존 팀플레이 본문 업데이트
    아트실 주간보고 새 업무 생성 + 댓글(이미지 포함)

    상태 표시¶

    • pending: 회색 시계 아이콘
    • running: 파란색 스핀 아이콘 + 프로그레스바
    • done: 초록색 체크
    • error: 빨간색 X + 오류 메시지

    7. Sync 규칙 (댓글 → Gantt)¶

    팀플레이 댓글을 파싱하여 Gantt 차트에 자동 반영합니다.

    반영 항목¶

    항목 동작 배지
    새 업무 "새 업무 등록" 감지 → Task 추가 신규 (주황)
    제목 변경 제목/프로젝트 변경 감지 → 업데이트 변경 (보라)
    완료 처리 댓글에서 완료 감지 → Done 완료 (초록)
    Work 마크 MM.DD 날짜 → workLogs 적용 작업 (파랑)

    배지 지속¶

    • 지속 시간: 1시간 (타임스탬프 기반)
    • 앱 재시작: 잔여 시간만큼 타이머 복원

    DailyNotes 동기화¶

    • 방식: noteCollector 패턴 — 같은 noteKey의 내용을 일괄 수집 후 교체 (append 아님)
    • 중복 제거: 동일 내용은 1개만 유지
    • 날짜 형식: dateKey (YYYY-MM-DD) 사용 — dateStr (MM.DD)와 혼동 주의

    8. 설정 위치¶

    Automation 패널 (단축키: A)¶

    설정 설명
    앱 시작 시 자동 Sync 시작 3초 후 자동 실행
    백그라운드 폴링 N분 간격 반복 Sync
    예약 자동 생성 설정 요일/시간에 팀플레이 생성
    댓글 정리 완료 프로젝트 제외 + 내용 초기화
    루틴 대상 팀플레이 / 아트실 선택
    LLM 문장 다듬기 아트실 댓글 LLM 처리
    목요일 알림 목요일 토스트 알림

    Weekly 패널 (단축키: K)¶

    설정 설명
    컬럼 선택 표에 포함할 컬럼 on/off
    조직 순서 조직 그룹 정렬 순서
    날짜 접두사 진행내용에서 날짜 제거
    URL 축약 Dooray URL 짧게 표시
    Task 정렬 원본순 / 프로젝트순

    Settings > 주간보고 그룹명¶

    설정 설명
    그룹명 매핑 조직 → 보고서 그룹 연결
    조직 추가/삭제 그룹별 조직 관리
